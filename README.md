# 🏐 SIPA - Filipino Traditional Game

**Sipa** is a web-based 3D rhythm game celebrating the traditional Filipino sport. Players must time their keystrokes to the music to keep the lead washer (shuttlecock) in the air, performing kicks and tricks in a vibrant, dynamic environment.

## 🎮 Features

-   **Rhythm Gameplay**: Hit notes in time with the music using 4 lanes.
-   **3D Visuals**: Immersive 3D environment built with A-Frame.
-   **Game Modes**:
    -   **Single Player**: Challenge yourself to beat your high score.
    -   **Multiplayer**: Turn-based competition to see who can score the highest.
-   **In-Game Shop**: Earn coins while playing to unlock:
    -   **Sipa Skins**: Classic, Golden, Fire, Neon, and Void styles.
    -   **Player Skins**: Customize your character's outfit.
    -   **Music Tracks**: Unlock genres like Rock, Jazz, Classical, and Electronic.
    -   **Environments**: Play on a Rooftop, Beach, Space Station, and more.
-   **Leaderboard**: Track your best scores locally.
-   **Dynamic Effects**: Visual feedback, combo systems, and particle explosions.

## 🕹️ Controls

| Key | Action |
| :---: | :--- |
| **A** | Hit Lane 1 |
| **S** | Hit Lane 2 |
| **D** | Hit Lane 3 |
| **F** | Hit Lane 4 |

> **Note**: Avoid hitting the 💣 bombs!

## 🚀 Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (latest LTS recommended)

### Installation

1.  Clone the repository or extract the project files.
2.  Open a terminal in the project directory.
3.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Game

Start the local development server:

```bash
npm run dev
```

Open your browser to the URL shown in the terminal (usually `http://localhost:5173/`).

## 🛠️ Technology Stack

-   **[Vite](https://vitejs.dev/)**: Frontend build tool.
-   **[A-Frame](https://aframe.io/)**: Web framework for building 3D/VR experiences.
-   **HTML5 / CSS3 / JavaScript**: Core web technologies.
